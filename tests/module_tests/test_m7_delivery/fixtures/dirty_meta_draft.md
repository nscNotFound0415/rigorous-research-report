## 2. 算力成本对比与口径分析

前轮内部测算表明单卡成本为 40.2 元每卡时。重工业用电基准价格稳定 [EVD-002]，为算力集群建设提供能源保障 [REF-01]。

本报告不给出最终毛利率结论，待商务洽谈后定案。
